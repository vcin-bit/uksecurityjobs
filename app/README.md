# UKSecurityJobs App

React frontend for app.uksecurityjobs.co.uk

## Stack
- React 18
- Clerk authentication
- React Router v6
- Deployed on Cloudflare Pages

## Development
```bash
npm install
npm start
```

## Deploy
Push to main branch — Cloudflare Pages auto-deploys.
Build command: `npm run build`
Build output: `build`
